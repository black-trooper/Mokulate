Mokulate（ZMK）では、キーマップを変更する方法が大きく分けて **3 種類** あります。  
それぞれ使い勝手や必要な作業が異なるため、目的に合わせて選んでください。


| 方法 | 再書込み | カスタマイズ性 | 備考 |
|------|-------------------|----------------|------|
| **DYA Studio** | 不要 | ◎ | キー以外の設定も可能 |
| **Keymap Editor** | 必要 | ○ | GitHub が必要 |
| **ファーム書換** | 必要 | ◎ | 全機能にアクセス可能 |


## DYA Studio

**最も簡単で、初心者におすすめの方法です。**

DYA Studio はブラウザ上でキーマップやキーボードの設定を編集できるツールです。キーの割り当てやレイヤーに加えて、対応するファームウェアではマクロ・コンボ、トラックボールなどの設定も変更できます。変更内容はキーボード本体に保存するため、編集のたびにファームウェアを書き換える必要はありません。

### 特徴

- ブラウザ上で操作でき、アプリのインストールは不要
- キー配置やレイヤーを画面上で編集できる
- 対応するファームウェアでは、マクロ・コンボやトラックボールなども設定できる
- 変更内容はキーボード本体に保存できる

### 簡易手順

0. キーボード側で studio_unlock キーを押します。標準キーマップで BLUETOOTH レイヤーにあります。  
（右手側の一番右下のキーを押しながらL）
1. [DYA Studio](https://studio.dya.cormoran.works/) を Chrome または Edge で開く
2. Mokulate の右側を USB ケーブルで PC に接続する
3. DYA Studio の接続画面で USB を選び、Mokulate に接続する
4. 編集したいキーを選んで、割り当てを変更する
5. 変更内容をキーボード本体に保存する

接続できない場合は、ファームウェアがDYA Studioに対応しているか確認してください。USB接続には、Web Serialに対応したブラウザが必要です。

## Keymap Editor

Keymap Editor は ZMK Config を *ブラウザ上で視覚的に編集するツール* です。  
GitHub Actions と連携し、自動ビルドされたファームウェアが生成されます。

**GitHub リポジトリを作り、編集した設定からファームウェアをビルドする方法です。**

### 特徴

- 自分の **zmk-config-Mokulate レポジトリ** が必要  
- キー配置やレイヤーを GUI で編集できる
- GitHub Actions により、編集した設定を含むファームウェアを自動生成できる
- GitHub Actions によりファームウェアを自動生成
- プログラミング不要だが、環境整備と GitHub 操作は必要

### 簡易手順

1. Githubアカウントを作成（既にお持ちの方は不要です）して、ログイン
2. [zmk-config-Mokulate](https://github.com/black-trooper/zmk-config-Mokulate) をフォーク
3. フォークしたリポジトリの Github Actions を有効化
4. [Keymap Editor](https://nickcoutsos.github.io/keymap-editor/) で編集
5. GitHub Actions によりファームウェアが生成される
6. [ファームウェアの書き込み手順](./firmware/#%E6%9B%B8%E3%81%8D%E8%BE%BC%E3%81%BF%E6%89%8B%E9%A0%86) に従い、書き込む

詳細な操作方法は **自分で調べて頑張ってください。**

## ファームウェアを書き換える

ZMK Config リポジトリ内の `.keymap` / `.overlay` ファイルを **直接テキスト編集してビルドする方法** です。

### 特徴

- 最も柔軟で細かいカスタマイズが可能  
  - 長押し判定の速さ（例：Z をどれくらい長押しすると Shift になるか）は変えたい
  - Hold-Tap の挙動カスタム（タップ優先／ホールド優先／クイックタップ時間など）
  - 「B と N を20ms以内に同時押ししたら Esc」「Ctrl を押してる時だけ無視」「優先順位は他より高め」みたいな細かい条件つきコンボ

### 備考

構文や設定など覚えることが多く、**高度なカスタマイズ向けです。**  
詳細は自分で調べてください。
